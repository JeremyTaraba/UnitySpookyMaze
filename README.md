# UnitySpookyMaze

# How To Install

In order to install the game you have to download the "Play Game" folder. 
To download this folder, navigate to https://download-directory.github.io/ and paste the url of this folder. 
For reference the url of this folder is: https://github.com/JeremyTaraba/UnitySpookyMaze/tree/main/Play%20Game

# How to Play

To play the game, unzip the folder and run the SpookyMaze.exe found in the folder.
